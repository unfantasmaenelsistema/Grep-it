Cómo usar el Patrón de Búsqueda

El patrón de búsqueda puede ser una palabra simple (ej: error) o una expresión regular para búsquedas más avanzadas.
Aquí tienes algunos ejemplos:

  • ^patrón: Busca líneas que **empiezan** con "patrón".
  • patrón$: Busca líneas que **terminan** con "patrón".
  • [0-9]: Busca cualquier dígito.
  • [a-z]: Busca cualquier letra minúscula.
  • .*: Busca cualquier caracter, cualquier número de veces.
